# 官方季度解析修正審查

本輪解析版本為 20。此報告不代表所有資料已補齊，也不是合併或部署批准。

## 獨立審查與修復

獨立唯讀審查發現，原本的內嵌報表補充只在整張表格確認美元單位，可能接受個別儲存格中錯誤的公司、期間或單位標記。使用真實 ABNB 申報樣本，單獨變更選定 EPS 的標記即可重現。原始未變更樣本的數字沒有因此被證明錯誤。

修正後先將數值位置對回實際儲存格，逐項驗證內嵌事實的公司與季度、單位、轉換格式、縮放、正負號及顯示數值的一致性。已含明示錯誤標記的儲存格不會退回無標記路徑；真正沒有標記的數值，另以季度表頭及表格美元證據核對，並記錄驗證依據。

十種錯誤標記反例及無標記正例均通過。獨立複查的 102 項相關測試通過，確認已重現的繞過問題封住，未提出其他可重現問題。

## 本輪其他修正

- 精確季度合併損益表補充缺漏的數值，保留欄位自己的來源。
- 排除預測、排除特定項目的 EPS，以及合資企業或其他非合併報表的數值。
- 保留原始衝突候選，只有能逐項對上排除證據時才解除假衝突。
- 扣利息費用後淨營收須由標準標籤及明示合併淨營收欄位相互確認；不任意選取不同口徑的數字。
- 同一份申報的較粗四捨五入披露不覆蓋原本較精確的核實數值。
- 從官方季度損益表的明示日期核對截止日；拒絕全年、預測、非損益表、未來或有多個可能近期截止日的情況。

## 驗證與限制

完整 Python 測試共 271 項通過。修正後另讀取 2,351 筆已快取季度申報，沒有檔案缺失或解析錯誤；對能重新取得的數值，沒有發現與候選資料不同的既有值。這是同一套解析規則的來源重讀，不能取代每個數值的獨立審查，也不能證明所有未能解析的欄位正確。

快取核對不確認來源的新鮮度。新解析版本仍須完成全站更新、逐筆差異、重跑一致性及最終網站操作檢查。獨立複查沒有重新審查既有發布／部署流程，也沒有透過網路核對全站每一筆資料。

使用者要求全部補齊並核實前，不得合併或部署正式網站。此條件仍未達成。
